# A New Hampshire Paradox: The Arsenic Extension

An object-oriented, statistically-rigorous companion analysis to the
*A New Hampshire Paradox* capstone, examining arsenic in New Hampshire
bedrock well water as the capstone's own excluded confounder.

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/<your-username>/<repo-name>/blob/main/A_New_Hampshire_Paradox_The_Arsenic_Extension.ipynb)

## Dataset

Lombard, Hayes, Andy, Fahnestock, Bryce, and Ayotte (2017), *Testing data
set for independent analysis of New Hampshire arsenic model*. U.S.
Geological Survey data release, [10.5066/F7XK8CQV](https://doi.org/10.5066/F7XK8CQV)
(CC0, public domain).
